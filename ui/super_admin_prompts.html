Cheat Sheet

ในกระบวนการวิเคราะห์จริง ระบบจะนำข้อมูลมาประกอบกันตามลำดับดังนี้:

  1. Default JSON Schema (บังคับ)
  2. Additional Instructions (ที่คุณพิมพ์)
  3. EXTERNAL CONTEXT (ถ้ามีการส่งมาจาก API)
  4. BUSINESS RULES (ดึงจากตารางกฎ)
  5. TRANSCRIPT (เนื้อหาการสนทนา)
Pro Tip: คุณไม่จำเป็นต้องอธิบายกฎทีละข้อในหน้าจอนี้ ให้ไปตั้งค่าใน "กฎกติกาการสนทนา (Compliance Rules)" แทน ระบบจะดึงมารวมให้เอง!
